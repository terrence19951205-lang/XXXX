# shell-hub app icons

Product: **shell-hub** (not 头盔工作台). Do **not** reuse x-hub’s purple + white X mark.

## Design
- Void background `#02040A` / plate `#0A1018` (matches HUD `--void`)
- Accent cyan `#00E5FF` (HUD `--cyan`)
- Mark: geometric **S** + HUD hex ring + corner ticks
- Tiny magenta spark `#FF2E97` (HUD accent), not an X
